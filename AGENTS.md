# Engineer repository instructions

The canonical skill is at this repository root. Read relevant source and tests
before changing it. `plugins/engineer/` is generated by `scripts/build-plugin.py`;
never edit it directly. Release version lives in SKILL.md metadata.

Preserve the instructions-only architecture. Host reasoning must not be repeated
by a new model/service. Deterministic checks and permission boundaries belong in
code; skill text is not an authorization mechanism.

Use English for code and documentation. Preserve consumer architecture and
lockfiles. Add regression coverage for fixes. Offline tests use explicit fixtures
and isolated homes. No authenticated model calls, host installs, network package
installs, destructive operations, commits, pushes, publishing, or deployment
without explicit authorization. `make setup` and `make install-*` are opt-in.

Run `make lint`, `make check`, `make test`, and `make verify-build`. Runtime source
edits invalidate illustrative skill-eval hashes: review changes, use the explicit
`make fixtures`, then rerun tests and `make build`. Do not manufacture captured
receipts. Keep historical research dates intact and record fresh verification in
a dated source ledger. State unavailable tools and unexecuted host tests honestly.
