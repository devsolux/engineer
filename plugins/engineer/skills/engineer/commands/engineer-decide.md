# /engineer-decide

Load `references/decision-engineering.md` and the relevant domain modules. Frame `$ARGUMENTS` as
alternatives, constraints, evidence, unknowns, reversibility, and kill criteria. Use two to four
distinct reasoning methods with blind independent positions, then cross-review and synthesize.
Do not force consensus. If Council is installed and the user requests deeper deliberation, compose
with it while keeping engineer responsible for repository evidence and engineering verification.
