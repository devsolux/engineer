# Contributing

Thank you for improving this project.

Before opening a pull request:

1. Check the README and existing issues for project-specific setup and scope.
2. Keep the change focused and explain the problem it solves.
3. Add or update tests and documentation when behavior changes.
4. Run the repository's documented formatting, lint, type, test, and build checks.
5. Disclose generated or AI-assisted material when its provenance or license matters,
   and review every submitted line yourself.

Do not include secrets, private data, unrelated generated files, or dependencies without
explaining why the dependency is necessary. Security vulnerabilities must follow
`SECURITY.md` when that policy is present; do not publish exploit details in an issue.

By submitting a contribution, you represent that you have the right to provide it under
this repository's license and contribution terms.
