# Verification ledger — 2026-10-22 module re-verification

Re-verification of reference modules past their review cadence, started on the committed 1.1.0
tree (e4d6f9a) on macOS 27.0.0 (arm64) with Python 3.11.17, Node 24.22.0, npm 11.19.1,
pnpm 12.14.0, uv 0.13.3, rustc/cargo 1.99.1, gh 2.102.0, Claude Code 2.1.282 and Codex CLI
0.163.0-alpha.11. Hermes, `tsc`, Supabase, Stripe, Vercel and Wrangler CLIs are not installed;
claims about them were checked against official documentation, registries and source.
The release ledger for 1.1.0 is [verification-2026-10-22.md](verification-2026-10-22.md);
research notes keep their own dates and are not re-verified here.

Method: each module's externally checkable claims (versions, dates, flags, API names, limits,
CVE subjects, named incidents and figures, product status) were listed and checked against a
primary source; engineering judgment was left as written. A module was redated only when every
such claim was checked. Findings below were spot-checked against the cited source before the
module was accepted.
