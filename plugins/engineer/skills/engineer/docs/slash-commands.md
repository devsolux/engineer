# Command catalog

Canonical workflows are shared by plugin and native adapters. Set `ENGINEER` to
the loaded skill directory when executing a bundled script; keep cwd in the target
repository. Native Codex prompt aliases use `/prompts:engineer-*`, while plugin
selection uses `$engineer`. The names below do not imply all hosts support aliases.
