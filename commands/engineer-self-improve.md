# /engineer-self-improve

Load `references/project-detect.md`, `references/skill-authoring.md`,
`references/refactoring.md`, and `references/workflows.md`.

1. Establish baseline: repo validator, fixtures, eval bank, skill health, git state.
2. Audit routing, module depth, workflows, scripts/templates, command parity, docs, research freshness, and real-project friction.
3. Rank gaps by recurrence, ship impact, and enforceability.
4. For multi-file work, write and validate `.engineer/plan.json`; execute only approved scope.
5. Prefer leaf references, templates, executable checks, and evals over growing `SKILL.md`.
6. Run complete verification and update gap audit/changelog with evidence.

Never weaken a gate merely to make the self-check green.
